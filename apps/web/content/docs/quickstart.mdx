---
title: Quickstart
description: Create a valve, queue API calls, and close it when the work finishes.
---

This page uses the default in-memory store, so you can run it without Redis.
For a budget shared between processes, see
[Share a quota across workers](/docs/guides/share-a-quota/).

## Before you begin

[Install valve](/docs/installation/) in a Node.js 20+ project with ESM enabled.

<Steps>
<Step>

### Create a valve

A valve is a named budget plus a local queue. This one allows 5 calls per
second and at most 2 running at once.

```ts title="quickstart.ts"
import { createValve } from 'valvejs';

const github = createValve({
  id: 'github:my-script',
  rate: { limit: 5, interval: '1s' },
  concurrency: 2,
});
```

</Step>
<Step>

### Queue work with run

`run` queues a function and resolves with its result. Types are preserved.

```ts title="quickstart.ts"
const users = ['octocat', 'torvalds', 'gaearon'];

const profiles = await Promise.all(
  users.map((name) =>
    github.run(async ({ signal }) => {
      const res = await fetch(`https://api.github.com/users/${name}`, {
        signal,
      });
      return (await res.json()) as { login: string; public_repos: number };
    }),
  ),
);

console.log(profiles.map((p) => `${p.login}: ${p.public_repos}`));
```

With the default `burst: 1`, grants are at least 200ms apart. Timers and other
work can delay callback execution.

</Step>
<Step>

### Or wrap fetch

`wrapFetch` returns a drop-in `fetch` that goes through the valve, reads rate
limit headers from every response, and retries 429s after the pause ends for
GET, HEAD, OPTIONS, PUT and DELETE. POST and PATCH require an explicit opt-in;
see [Requests with side effects](/docs/guides/respect-retry-after/#requests-with-side-effects).

```ts title="quickstart.ts"
const githubFetch = github.wrapFetch();
const res = await githubFetch('https://api.github.com/rate_limit');
```

</Step>
<Step>

### Close the valve

`close` stops accepting work and waits for running jobs. Pass `drain: true`
to also run everything still queued.

```ts title="quickstart.ts"
await github.close({ drain: true });
```

</Step>
</Steps>

## Run it

```sh
npx tsx quickstart.ts
```

<span id="what-you-learned" />

The default store is private to this valve. Creating another valve with the
same `id` creates a separate budget unless you pass both the same store.
Valves share a budget only when their `id` and store match.
