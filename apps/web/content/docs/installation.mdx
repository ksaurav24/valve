## Requirements

- Node.js 20 or later. The core uses web standard APIs only.
- For shared budgets: Redis 6.2 or later, or Valkey 7.2 or later.
- For shared budgets: a connected [`ioredis`](https://github.com/redis/ioredis)
  or [`node-redis`](https://github.com/redis/node-redis) client (v4 or v5).

valve has no runtime or peer dependencies. It never imports a Redis client; it
uses the one you pass in.

## Entry points

| Import            | Contains                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------- |
| `valvejs`         | `createValve`, `memoryStore`, `ValveError`, `isValveError`, `defaultFeedback`, and the public types. |
| `valvejs/redis`   | `redisStore` and the structural client and adapter types.                                            |
| `valvejs/headers` | Feedback readers: `retryAfter`, `ietfRateLimit`, `xRateLimit`, `combine`, `defaultFeedback`.         |

Each entry point ships as ESM and CommonJS with TypeScript declarations.

```ts
// ESM
import { createValve } from 'valvejs';

// CommonJS
const { createValve } = require('valvejs');
```

## Connect a Redis client

You only need Redis when more than one process shares a budget. Create and
connect the client yourself. valve never opens or closes it.

<Tabs items={['ioredis', 'node-redis']}>
<Tab value="ioredis">

```ts
import { Redis } from 'ioredis';
import { redisStore } from 'valvejs/redis';

const redis = new Redis(process.env.REDIS_URL!);
const store = redisStore({ client: redis });
```

</Tab>
<Tab value="node-redis">

```ts
import { createClient } from 'redis';
import { redisStore } from 'valvejs/redis';

const redis = await createClient({ url: process.env.REDIS_URL }).connect();
const store = redisStore({ client: redis });
```

</Tab>
</Tabs>

An ioredis `Cluster` instance also works. For any other client, pass an
[adapter](/docs/reference/redis-store/#bring-your-own-client).
