# Security Policy

## Supported versions

Security fixes are prioritized for the latest released version of `valvejs`. Older versions may not receive updates while the project is in early development.

## Reporting a vulnerability

**Do not report suspected vulnerabilities through public issues, discussions, or pull requests.**

Use [private vulnerability reporting](https://github.com/ksaurav24/valve/security/advisories/new) when enabled. If unavailable, email **ksaurav4093@gmail.com** with the subject `[Valve Security] Vulnerability report`.

Include the affected version; Node.js, Redis/Valkey versions and deployment topology; the security impact; reproducible steps or a minimal proof of concept; and possible mitigations. Do not send real credentials or production data.

We will acknowledge and investigate reports as capacity allows, coordinate remediation and disclosure, and publish advisories when appropriate. There is no guaranteed response or remediation timeline. Please avoid public disclosure while a report is being investigated.

## Security updates

Security fixes and affected versions will be documented in GitHub security advisories and release notes when appropriate. Regular bugs and feature requests belong in [Issues](https://github.com/ksaurav24/valve/issues).
